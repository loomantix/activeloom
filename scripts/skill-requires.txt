# Skill dependencies, read by scripts/install-skills.sh and `activeloom add`.
#
#   <skill>: <required ...> | <optional ...>
#
# Required: the skill reads or runs another skill's files, or hands its normal
# work to that skill, and fails partway through without it. Installers install
# the required closure and report any required skill that is missing.
# Optional: the skill names or suggests another skill (a hand-off the user may
# take, a hosted or retired path). Never installed or reported.
#
# Names are harness-neutral; a dependency a harness root does not ship is
# skipped for that harness. tests/test_skill_requires.py fails when a skill
# references another skill's files without declaring it required, or invokes
# one without declaring it at all.
